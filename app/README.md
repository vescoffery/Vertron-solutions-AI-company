# Vertron Solutions

Enterprise-grade AI automation and autonomous agent systems.

## Overview

Vertron Solutions builds and operates production AI workforces for serious businesses. We specialize in multi-agent orchestration using Hermes Gateway, advanced n8n workflows, and custom autonomous agent fleets.

This repository contains the official marketing website for Vertron Solutions.

## Tech Stack

- **Framework**: Next.js 15 (App Router) + TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Deployment**: Vercel
- **Domain**: vertronsolutions.com (Cloudflare)
